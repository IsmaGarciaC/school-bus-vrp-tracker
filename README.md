# Busetas Dashboard - Optimizador de Rutas Escolares (Cuenca)

Plataforma interactiva para la gestión, geolocalización y optimización de rutas de transporte escolar en la ciudad de Cuenca, Ecuador.

## 🎯 Objetivo del Proyecto
Diseñar un sistema completo (Frontend + Backend + Motor de Optimización) que permita:
1. Visualizar e interactuar con el mapa urbano de Cuenca.
2. Registrar estudiantes y puntos de recogida de forma manual en el mapa.
3. Sectorizar geográficamente las paradas para evitar cruces de rutas.
4. Resolver el problema de ruteo de vehículos (VRP) para asignar paradas eficientes a una flota de busetas escolares.

## 🧱 Arquitectura Planificada
- **Frontend:** Dashboard web interactivo (HTML5, CSS3, JavaScript, Leaflet.js).
- **Backend:** API REST en Python (FastAPI).
- **Motor de Optimización:** Google OR-Tools (Vehicle Routing Problem).
- **Control de Versiones:** Git y GitHub con commits convencionales.
